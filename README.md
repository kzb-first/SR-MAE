# SR-MAE v1.0



## Introduction
Super-resolution global weather forecasting with a masked autoencoder backbone

## Installation
This project provided an environment seeting file of conda,users can easily reprodece the environment by the following commands
```
conda env create -f environment.yml
conda activate SR_MAE
```

## W-MAE pretrain weight 

The pre-trained weights of W-MAE can be downloaded from https://drive.google.com/file/d/15iaB_i_sYvlSQ7C8iAWeNIDjCaGvdVcn/view.

## train and test 

To training or testing, use 
```
python main.py
```
